# Pizza Sales Analysis Dashboard

This project contains a Power BI dashboard and Python scripts to analyze pizza sales.

## Files

- `pizza_sales_dashboard.pbix`: Power BI interactive report
- `pizza_sales_analysis.py`: Python (pandas/matplotlib) analysis script

## Visualizations
- Total revenue, orders, top pizzas
- Revenue by size/category
- Sales trend by date/time

## Requirements (Python)
- pandas
- matplotlib
